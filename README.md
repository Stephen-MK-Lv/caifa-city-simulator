## 2026-10-09 荆州公开数据参考方案

上一级目录的“启动荆州参考示范.cmd”使用独立示范数据库及8766端口，已准备期初和全年示范账套；与原8765课堂入口分开。已运行时直接访问 http://127.0.0.1:8766 。上一级“荆州参考仿真数据_2025”文件夹提供0月/12月数据包、公开数据与仿真假设JSON、图景预览。数据包供分析，不是可导入恢复的数据库备份。

重启服务并刷新网页，在“新建独立账套”中选择“荆州公开数据参考”。旧账套不改写；仍可选择原教材基准方案。相同方案、版本、种子和操作序列可重演。

人口采用荆州2025年常住人口的1/100，即50,829人。724个示范岗位由行业缩尺与教材假设组成，不是全市就业存量；6.70万人为年度新增就业流量。未检索到可核验的实际国库存款余额，期初48,582,500元为“一月平均一般公共预算支出÷100”的教学资金储备假设，不是实际余额估计。数据来源、口径、假设、业务方式可在城市总览展开，导出包附“仿真数据依据.json”。

财政局居中，公安局和职业学校位于左侧，人民医院和城市实业有限公司位于右侧，四主体同层级。连线表示资金关系，不表示行政隶属。新方案罚款直接缴国库，公安局不确认收入；原教材方案保留原代收缴库演示。各单位不是荆州真实单位，也不是完整城市财政数字孪生。多年运行可能因资金不足或预算限额暂停。
